# Rubric: Grilling Interview Quality

The output must be a grilling interview about a task plan for a tiny
greeting CLI. Score each criterion and average them:

1.  **Interview**: at least one grilling round with several concrete,
    plan-specific questions was conducted (questions about validation,
    interface, or verification of the greeting tool, not generic
    filler).

2.  **Alternatives**: the questions offered grounded answer
    alternatives, with the alternative reflecting the current plan
    marked.

3.  **Focus areas**: the questions carried focus areas (such as DOMAIN,
    INTERFACE, ARCHITECTURE, IMPLEMENTATION, REGRESSION, or
    CONFIRMATION).

4.  **Resolution**: the interview concluded (the plan was updated with
    the answers, or the grilling was explicitly finished), rather than
    stopping mid-way with unprocessed answers.
