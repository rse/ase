# Rubric: Brainstorm Session Quality

The output must be a complete brainstorm session on the topic of a
command-line tool which reminds developers of stale local Git branches.
Score each criterion and average them:

1.  **Divergence**: at least 8 distinct candidate ideas were generated,
    pursued from visibly different angles (not rephrasings of one idea).

2.  **Convergence**: the ideas were clustered into coherent themes and
    scored on a fit scale, with low-fit ideas visibly pruned.

3.  **Shortlist**: a shortlist of at most 3 directions was distilled,
    drawn from distinct clusters where possible.

4.  **Recommendation**: a single final recommendation was derived, with
    a stated rationale tied to the scoring or synthesis.

5.  **Topicality**: all ideas genuinely concern stale local Git branch
    detection or reminding, not generic developer tooling.
